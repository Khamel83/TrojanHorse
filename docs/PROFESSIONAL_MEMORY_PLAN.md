# TrojanHorse first useful product

Decision checkpoint: 2026-10-05. Professional memory is the provisional first
product, pending the owner's answer about priority. The immediate request was
package incorporation, not implementation or publication of a new application.

TrojanHorse already has ingestion, exact search, evidence views and a read-only
answer CLI. It has technical plans and verification receipts. What remains
unproven is an everyday workflow that answers the owner's questions reliably.
Successful scraping and import do not establish that product outcome.

## The useful workflow

Ask “Have I dealt with this kind of problem?” or “What did I actually contribute?”
Retrieve relevant project cards, follow their evidence pointers, and return a
short answer with dated source passages. Show Omar's contribution separately
from staff work; distinguish research, recommendation, approval, implementation
and measured outcome. Show unresolved contradictions and missing outcomes.
Retain owner corrections with attribution rather than rewriting the raw archive.

The receiving professional corpus is a downstream consumer. TrojanHorse should
provide a factual, retrievable memory and export changes when requested. Board
positioning, résumé copy and website text are interpretations of that memory.
They do not become independent historical evidence when imported here.

## Scope boundaries

Active-task management and broad personal memory remain separate choices.
No deployment, public publishing, external communication, remote-model transfer
or résumé/site changes are part of this intake. Sensitive evidence stays local.
Reopen historical sources only for a named gap, newly available source/version,
or an objective that retained facts cannot answer; first examine existing cards
and extracts. Preserve stopped projects and counterevidence.
